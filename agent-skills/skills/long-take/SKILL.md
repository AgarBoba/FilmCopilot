# 一镜到底长镜头

目标：一条从头到尾没有剪辑感的连续视频。做法分两半：**先按模型的功能选路线**（模型会变，所以只看功能，不认模型名），**再按通用的门道规划和检查**。

## 1. 先弄清楚要什么

- 总时长、画幅、要不要声音；从哪个画面开始、在哪个画面结束（有没有指定的首帧 / 尾帧图）。
- 用户连了哪些参考：角色、场景、产品、动作或运镜参考视频。
- 拿不准的一次问清楚，别边做边问。

## 2. 查功能，选路线

用 `list_models(kind="video")` 看每个模型的「功能」和时长参数（duration 的最大值就是单次最长）；选定后用 `get_model_guide` 读完整说明，再按说明里写的提示词技能写 Prompt。按下面的顺序，**用第一条走得通的**：

| 顺序 | 条件 | 做法 | 好处 / 代价 |
|---|---|---|---|
| A | 有模型单次最长 ≥ 总时长 | **一次生成**整条，不拼接 | 最自然，没有接缝。首选 |
| B | 有 `video_extend` | 先生成第 1 段，再一轮一轮「向后延长」 | 衔接最顺；延长多了画面会慢慢跑偏，每轮都要检查 |
| C | 有 `first_last_frame` | 先把每个衔接点的画面做成图（关键帧），再逐段用「首帧 = 上一个关键帧，尾帧 = 下一个关键帧」生成 | 每个接点都由你控制，不会越接越偏；要先多出几张图 |
| D | 只有 `first_frame` | 生成一段 → `extract_frame` 取末帧 → 当下一段首帧，循环 | 最通用；运动速度、方向可能接不上 |
| — | 都没有 | 做不了一镜到底。告诉用户，建议改成几个镜头剪在一起 | |

B、C 也可以混用：比如一次生成 30 秒（A）之后，不够长的部分再延长（B）。

## 3. 规划：先给用户看方案和价钱

1. 分段：每段不超过模型单次最长时长，**分得越少越好**（每多一个接缝就多一次出错机会）。
2. 衔接点：选在动作慢、镜头匀速移动的时刻；不要选在转身、跳跃、快速甩镜头的瞬间。
3. 每段写清楚：这段发生什么、运镜方向和速度、结束时停在什么状态（下一段从这里开始）。
4. 统一设定写一次、每段都带上：人物长相、服装、场景、光线色调、画面质感、声音氛围。可以建一个「全局设定」文本节点连到每段。
5. 算钱：每段的价格（list_models 里有）× 段数，加上可能的重做。**连续生成前把分段表和总价发给用户确认。**

在画布上按时间从左到右排：每段一个视频节点（标题写「段 1 · 0–15 秒」这类），全局设定文本节点放最左边，必要时用便签标出「一镜到底」这一组。

## 4. 各路线的具体做法

### A 一次生成
- 时长直接设成总时长；提示词按时间段写：「[0-10秒] …；[10-20秒] …；[20-30秒] …」。
- 写明「单个连续镜头，无剪辑，镜头平滑运动」，每个时间段写清楚运镜。

### B 延长视频
1. 生成第 1 段。
2. 新建下一段的视频节点，**只连上一段**（参考视频总时长有上限，别连拼好的长视频），提示词写「向后延长 [Video1]」+ 接下来发生什么 + 要保持什么（人物、场景、风格、声音）。参数按模型说明设（比如画幅要 adaptive）。
3. 生成完先看时长：比设的时长长很多，说明结果里带了原视频；否则就是只有新增的一段。
4. 重复直到够长，最后用 `join_videos` 按顺序拼起来；结果里带了原视频的那段，用 start 裁掉重复部分。

### C 首尾帧接力
1. 先生成 / 准备好关键帧图：K0（开头）、K1、K2……（每个衔接点一张）。关键帧之间画面变化别太大，人物和场景要一致（可以用图片模型参考同一组角色图来出）。
2. 第 n 段：首帧连 K(n-1)，尾帧连 Kn（注意连线顺序：第 1 条是首帧，第 2 条是尾帧）。
3. 全部生成后 `join_videos` 拼接。两段共用的关键帧会在接点处重复一帧，影响不大；介意的话把后一段 start 设成 0.05。

### D 末帧接力
1. 生成第 1 段。
2. `extract_frame(上一段, at="last")` 得到末帧图，连到下一段当首帧；提示词里写清楚这段的动作要**接着**上一段的方向和速度。
3. 重复，最后 `join_videos`。

## 5. 检查接缝（每生成一段就查，不要等全部做完）

- 用 `view_asset` 看上一段结尾和这一段开头：人物位置、朝向、服装、光线、颜色有没有跳；运动方向和速度是不是连着的。
- 跳得明显就**只重做这一段**（改提示词或换衔接点），别硬往下接。
- 拼好后再用 `view_asset` 看一遍整条视频，告诉用户接缝在第几秒、哪里可能还有小瑕疵。

## 6. 常见坑

- 一段写太多事：一段只写一两个动作，事多就多分段。
- 越接越偏（脸、衣服慢慢变了）：路线 B、D 每两三段就对照一下最开始的角色图；偏了就改用路线 C，用关键帧把画面拉回来。
- 声音断开：每段都写同样的环境声；台词别跨接缝。
- 模型说明里的「输入限制」和「已知问题」要照做（参考视频时长、画幅、真人限制等），不然会生成失败白花钱。
