# 写 Seedance 2.0 提示词

Seedance 2.0 是全能参考模型：图片、视频都可以连进来，模型按提示词判断每个参考怎么用。下面的写法按官方说明整理，具体限制以 get_model_guide 里的说明为准。

## 1. 先数清楚参考

用 get_node 看节点：它会按连线顺序列出 [Image1]、[Image2]……[Video1]。提示词里只用这些编号，不要写节点名称。

## 2. 每个参考写一句用途

常见用途：

- 角色：「[Image1] 中的女孩」——长相、发型、服装跟随这张图。
- 场景：「场景参考 [Image2]」。
- 开场画面：「以 [Image1] 作为开场画面」——会尽量贴近，但不保证逐像素一致。
- 镜头运动 / 动作：「镜头运动参考 [Video1]」「动作参考 [Video1] 中人物的舞步」。
- 风格：「整体色调和质感参考 [Image3]」。

没写用途的参考，模型会自己猜，结果不稳定。

## 3. 一个镜头的写法

按这个顺序写成一段话：

1. 主体和动作（一个镜头只写一个主要动作）；
2. 镜头：景别和运镜（推、拉、摇、移、跟、环绕），节奏快慢；
3. 光线、氛围、色调；
4. 声音（打开声音时）：环境音、音效、台词（台词用引号写出原话）。

例：

```prompt
[Image1] 中的女孩站在 [Image2] 的老街路口，回头看向镜头，红色斗篷被风吹起。镜头从中景缓慢推近到近景，运动方式参考 [Video1]。黄昏暖光从左侧照来，街道有薄雾。环境音：远处的叫卖声和风声。
```

## 4. 别这样写

- 10 秒里塞三四个动作：拆成几个 5 秒的镜头。
- 堆关键词（「女孩, 老街, 黄昏, 电影感」）：写成完整的一段话。
- 要求画面里出现大段文字：后期加。
