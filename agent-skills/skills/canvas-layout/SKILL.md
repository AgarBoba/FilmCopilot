# 整理画布

只移动节点，不改内容、不删节点、不改连线。

## 步骤

1. get_canvas 看清所有节点、位置、连线。
2. 找出「流」：沿连线从上游到下游，每条链是一组（设定便签 → 镜头便签 → 图片 → 视频）。没有连线的节点按类型和名字归到一起。
3. 排位规则：
   - 上游在左、下游在右，按链的层级分列：第 1 列是最上游（设定、参考素材），往右依次是镜头便签、图片、视频。
   - 列间距约 400，行间距约 420（图片 / 视频节点比较高）；同一列左对齐。
   - 同一组链从上到下按镜头顺序排（看名字里的编号，如「镜头 1」「镜头 2」）。
   - 不同的组之间空出一行，组内保持紧凑。
   - 尽量以原来最左上节点的位置为起点，别把整张画布挪远。
4. 一次 move_nodes 把所有位置传完，不要一个节点一次。
5. 移动前用一句话说要怎么排（比如「按 3 条链从左到右排，设定便签放最左」）；节点超过 15 个时先等用户同意。

## 收尾

说一句排完的结构（几组、每组几个节点），并提醒用户：不满意可以点面板里的「撤销这一轮的改动」恢复原来的位置。
