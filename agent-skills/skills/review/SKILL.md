# 点评作品

## 步骤

1. 确定要看哪些：用户选中的节点；没选就是刚生成完的那一批。用 view_asset 逐个看（视频会给你几帧截图）。
2. 回到要求：每个节点的 Prompt、连着的便签和参考图、[项目记忆]里的风格设定，就是评判标准。
3. 按这几项看，每项只记有问题的：
   - **符合要求**：主体、动作、场景是不是 Prompt 说的那样。
   - **一致性**：角色 / 产品和参考图、和其他镜头像不像。
   - **构图和镜头**：主体位置、景别、留白，视频的镜头运动是否顺。
   - **光线和氛围**：和设定的基调是否一致。
   - **瑕疵**：手指、脸部变形、多余的物体、文字错误、视频里的闪烁和突变。
4. 给结论：
   - 先说最好的是哪个，一句话理由。
   - 其余每个一句话：主要问题。
   - 给 1–2 条具体的改进，写成可以直接用的 Prompt 修改（「把『侧光』改成『清晨从左边窗户照进来的侧逆光』」）。

## 原则

- 说具体的画面，不说空话（不写「整体不错」「很有氛围感」）。
- 只是点评，不自己重新生成；用户同意后再按改进意见改 Prompt、重新生成。
- 用户已经表态喜欢哪个时，尊重他的判断，可以补充你的看法。
