# 写生成提示词

## 先看用的是哪个模型

用 list_models 看节点用的模型：它擅长什么、接受几张参考图、有哪些参数。下面是通用写法，模型说明里有特别要求的以模型说明为准。

## 图片提示词

按这个顺序写成一段完整的话（不是关键词堆砌）：

1. **主体**：是谁 / 是什么，具体特征（「一只米白色垂耳兔，耳朵内侧淡粉色」，而不是「兔子」）。
2. **动作和状态**：在做什么、表情、姿态。
3. **场景**：在哪、周围有什么、时间。
4. **光线**：光从哪来、什么质感（清晨侧逆光、阴天柔光、霓虹灯反光）。
5. **镜头和构图**：景别（特写 / 中景 / 远景）、视角（平视 / 俯拍 / 低角度）、主体在画面哪里、景深。
6. **风格和质感**：写实摄影 / 3D / 插画 / 胶片颗粒……需要时说明参照（「90 年代日本动画质感」）。

经验：
- 要什么就写什么，少用否定（「不要」常常反而让模型画出来）。
- 画面里要出现文字时，把文字原样用引号写出，并说明位置。
- 中英文都可以；模型说明或[我的偏好]有指定时照做。

## 视频提示词

视频是「图 + 时间」。有首帧参考图时，**不要重复描述图里已有的东西**，重点写：

1. **动作**：主体从什么状态变成什么状态，一个镜头一两个动作就够。
2. **镜头运动**：推、拉、摇、移、跟、环绕、手持晃动、固定机位；写清方向和快慢（「镜头缓慢向前推近到兔子的脸」）。
3. **节奏**：需要时按时间写（「前 2 秒…，之后…」）。
4. **氛围变化**：光线变化、风、粒子、景深变化。

经验：
- 动作要和时长匹配：5 秒做不完「走进厨房、做饭、吃完」。
- 要角色 / 产品不走样，就连上清晰的参考图，并在提示词里用同一组描述词。

## 参考图怎么用

- 参考图决定「像谁、长什么样」，提示词决定「在做什么、什么场景」。
- 想保持一致：连同一张主参考图到所有相关节点。
- 参考图之间别打架：风格完全不同的几张图一起连，结果会四不像。
- 便签适合放所有节点共用的设定，连上之后它的文字会放在节点 Prompt 前面，节点自己就不用重复写。

## 生成得不对时

先 view_asset 看结果，判断是哪一层的问题：
- 主体不像 → 加强主体描述或换更清楚的参考图。
- 构图不对 → 写明景别、视角、主体位置。
- 风格跑偏 → 风格词放前面、加参照，检查是否有风格冲突的参考图。
- 视频动作乱 → 减少动作数量，写清镜头运动。

一次只改一两处，说明改了什么、为什么，让用户决定要不要重新生成。

## 写进画布

提示词写进节点的 Prompt（update_node），或放进对话里的 ```prompt 代码块，方便用户一键存成便签。
