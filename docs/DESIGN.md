# Film Copilot 设计规范

> 用途：统一画布的界面和交互。新增或修改界面前先读这份；改了规范就同步更新这里。
> 样式都在 `web/src/styles.css`，颜色和尺寸尽量用下面的变量，不要写死数值。

## 1. 原则

1. **画布优先**：界面控件都是浮在画布上的小块，不占整行、不挡内容。
2. **图标 + 气泡**：没有文字的按钮一律要有悬停气泡，说清楚这个按钮是干什么的（见第 6 节）。
3. **状态就近显示**：节点自己的状态（生成中、失败）显示在节点里，全局问题（保存失败）显示在顶部提示。
4. **中文界面**：所有给用户看的文案用中文，标点用全角。

## 2. 布局

| 位置 | 内容 | 组件 |
| --- | --- | --- |
| 左侧垂直居中 | 「+」添加节点、上传 | `canvas/CanvasRail.tsx` |
| 左下角 | 鼠标 / 抓手 ｜ 缩小、缩放比例、放大、Fit ｜ 连线显示、深浅色、保存状态 | `canvas/CanvasControls.tsx` |
| 右下角 | 小地图 | React Flow `MiniMap` |
| 顶部居中 | 出错提示（可关闭） | `CanvasShell.tsx` 里的 `.canvas-toast` |

浮层离屏幕边缘统一留 **16px**（`.react-flow__panel.canvas-panel`）。

## 2.1 画布操作

| 操作 | 触控板 | 鼠标 | 键盘 |
| --- | --- | --- | --- |
| 平移画布 | 双指滑动 | 滚轮（Shift + 滚轮左右移） / 中键拖动 | 按住空格拖动；H 切换到抓手 |
| 缩放 | 双指捏合 | Cmd / Ctrl + 滚轮 | 左下角 − / ＋ |
| 框选 | 在空白处按下拖动 | 在空白处拖动 | V 切换到鼠标 |

- 缩放范围是 10%–400%，缩放时以手指或鼠标所在的位置为中心。
- 双击空白处不会缩放，避免误触。
- 在能滚动的文本框上双指滑动，滚动的是文本框里的文字，不会平移画布。
- 视口位置在停止操作 0.6 秒后保存，不会每滑一下就保存一次。
- Safari 的捏合手势由 `canvas/useTrackpadGestures.ts` 单独处理，否则整个网页会跟着缩放。

### 复制节点

| 方式 | 效果 |
| --- | --- |
| 按住 Option（Windows：Alt）拖动节点 | 原节点留在原地（拖动时显示为半透明），松手处生成副本 |
| ⌘D（Windows：Ctrl+D） | 在选中节点右下方 40px 处生成副本，可一次复制多个 |
| 「⋯」菜单 →「复制节点」 | 同 ⌘D，只复制这一个 |

- 副本带上内容、Prompt、参数、尺寸，名字加「副本」后缀；复制完成后选中副本。
- 副本保留输入连线（参考图、便签），不复制输出连线；一起复制的节点之间的连线会连到新副本上。

## 5. 组件

### 节点

从上到下：

1. **标题栏**：类型标签 ＋ 可编辑名称 ＋「⋯」更多操作。节点的操作都收进「⋯」菜单（`nodes/NodeMenu.tsx`），不在节点上直接放大按钮。
   - 图片/视频节点的菜单：上传、下载、全屏查看。
   - 暂时不能用的菜单项置灰，悬停气泡说明原因（如「还没有图片，无法下载」）。
   - 菜单固定大小，不随画布缩放；平移或缩放画布时自动关闭。
   - 下载的文件以节点名称命名（如「胡萝卜尝试.jpg」）。
   - 全屏查看：全窗口深色遮罩，右上角有下载和关闭；Esc 或点击遮罩关闭，打开期间画布快捷键不生效。
2. **预览区**：图片或视频；生成状态盖在预览区上面（见下文）。
3. **参考图条**（有参考素材时才显示）。
4. **Prompt 区**：输入框 ＋ 模型参数 ＋「生成」按钮。

名称：新建节点自动命名为「图片 1」「视频 2」这类格式；点一下就能改，回车或点别处保存，Esc 放弃修改，清空后恢复原来的名字。

### 便签作为提示词

- 便签只有右边的输出端，没有输入端；只能连到图片或视频节点。
- 生成时，上游便签的文字（按连线先后顺序）放在节点自己的提示词前面，用空行隔开，一起发给模型。没有文字的便签会被跳过。
- 下游节点的参考素材栏里，便签显示为一张文字卡片（便签名称和开头一段文字），悬停可以看到全文，点 × 断开连线。
- 连了有文字的便签时，Prompt 框下方会提示「上游 N 条便签的文字会放在这段提示词前面」，Prompt 框也可以留空。

### 参考素材栏滑动

- 放不下时横向滑动：触控板左右滑、鼠标滚轮（竖向滚动会转成横向）、或点两侧的圆形箭头（每次翻约一屏）。
- 有更多内容的一侧会渐隐，并显示箭头；滑到头箭头消失。
- 指针在素材栏上时滚动不会平移画布；双指捏合仍然缩放画布。

### 上游有更新（`nodes/UpstreamBadge.tsx`）

- 生成结果**总是**放进节点，即使生成期间上游变了（只有节点被删时才不放）。
- 结果生成之后，上游便签文字改了、上游图片 / 视频的内容换了、新连或断开了参考，节点正上方出现琥珀色小标签「上游有更新」，多项时显示数量。
- 悬停标签列出具体变化，并提示「重新生成可使用最新内容」；重新生成后标签消失。
- 节点自己的 Prompt、参数改了不算上游更新。生成中不显示。

### 视频播放（`nodes/VideoPlayer.tsx`）

- 预览区底部浮一条播放控件：播放/暂停、进度条（可拖动）、时间、声音开关。
- 控件在鼠标悬停节点或视频暂停时显示，播放中移开鼠标会自动隐藏。
- 鼠标悬停节点时静音预览播放，移开就停下并回到开头。
- 用户点过播放控件之后，就由用户控制：移开鼠标不会自动暂停；视频暂停后再移开，才恢复悬停预览。
- 点击视频画面本身也能播放或暂停。默认静音，点声音按钮打开。

### 生成状态（`nodes/GenerationOverlay.tsx`）

| 状态 | 预览区显示 | 可操作 |
| --- | --- | --- |
| 排队中 / 生成中 | 半透明遮罩 ＋ 转圈 ＋「排队中…」/「生成中…」 | 「生成」、上传、Prompt、参数、移除参考都锁定，Prompt 区下方提示「生成中，完成后才能修改提示词和参数」 |
| 失败 | 淡红底 ＋「生成失败」＋ 最关键的一行原因；悬停气泡显示完整报错 | 可重新生成 |
| 完成 | 直接显示结果 | 全部可用 |

### 端点

- 左边是**输入端**，右边是**输出端**，都在节点边缘垂直居中。
- 端点元素本身保持 12px，连线从这里开始画；外面有一圈 40px 的透明区域，方便点中。
- 圆点：平时 14px；悬停或拖线时放大到 24px 并显示「+」；拖线时连不上的端点会变灰。
- 平时隐藏，鼠标悬停节点或选中节点时才显示。

### 菜单

「+」菜单和拖线后弹出的菜单用同一套规则：点菜单外面、按 Esc、平移或缩放画布都会关闭；打开后键盘焦点在第一项；靠近屏幕边缘时自动往里收。

### Agent 对话面板（`web/src/agent/`）

- 右侧浮层，宽 400px；左侧栏的 ✦ 按钮或 ⌘J 打开 / 关闭。打开时小地图左移让位。
- 顶部：新对话、关闭；历史对话下拉、权限档位下拉。
- 消息：你的消息右侧紫色气泡（带「关注：…」）；Agent 回复左侧，Markdown 渲染（表格可横向滑动），悬停出现「复制」「存到画布」；工具步骤是一行灰色小字，点击定位到节点，出错的标「未完成」；待确认操作是琥珀色卡片（确认 / 拒绝）。
- 回复流式显示，末尾有闪烁光标；等待时显示三个跳动的点。
- 一轮结束且有改动时，显示「撤销这一轮的改动」。
- 输入框：Enter 发送，Shift+Enter 换行（中文输入法选词时的回车不发送）；运行中按钮变成「停止」。画布快捷键在面板里不生效。

### 便签 Markdown

- 便签文字按 Markdown 渲染（标题、列表、表格、代码）；双击或聚焦后按 Enter 编辑原文，点外面或 Esc 结束。
- 空便签显示「双击输入文字」。

## 6. 气泡提示（Tooltip）

**规则：只有图标、没有文字的按钮，必须同时有 `aria-label` 和 `data-tooltip`。** 有文字但作用不直观的（比如缩放比例、Fit）也要加。

写法：

```tsx
<button
  aria-label="抓手工具"                             // 读屏用，写简短名称
  data-tooltip="抓手：拖动画布（按住空格可临时切换）"  // 气泡文字
  data-tooltip-shortcut="H"                        // 可选：快捷键
  data-tooltip-side="right"                        // 可选：top（默认）/ bottom / left / right
>
```

- 气泡由 `canvas/TooltipLayer.tsx` 统一显示，不要再用浏览器自带的 `title`，否则会同时冒出两个提示。
- 显示时机：悬停 350ms 后出现；一个气泡刚消失时，移到相邻按钮会马上出现；用键盘 Tab 聚焦时立刻出现。点击、滚动、按 Esc 都会让它消失。
- 位置：优先显示在指定的一侧，放不下就换到对面，并且不会超出屏幕。侧栏上的按钮气泡朝右，底部控件条上的朝上。
- 按钮暂时不能用时，用 `aria-disabled="true"`，**不要用 `disabled`**：浏览器不会给 `disabled` 的按钮触发悬停事件，气泡就出不来了。气泡文字要说明为什么不能用，比如「生成中，暂时不能上传」。

气泡文案：

- 格式是「**名称：做什么**」，简单的按钮只写名称（如「放大」）。
- 说结果，不说操作步骤：写「缩放到能看到全部节点」，不写「点击此按钮以适配视图」。
- 一句话以内，不加句号。

## 7. 文案

- 按钮用动词：添加、上传、生成、移除。
- 状态用「…中」加省略号：保存中…、生成中…。
- 出错写清楚发生了什么，比如「上传失败：只支持图片或视频」。

## 8. 动效

- 悬停、展开类过渡控制在 120–160ms，用 `ease` 或 `ease-out`。
- 转圈动画 0.9 秒一圈；用户在系统里开了「减少动态效果」时要放慢或关掉动画。

## 9. 新增界面自查清单

- [ ] 颜色、圆角用的是上面的变量和档位，没有写死新的数值
- [ ] 深色、浅色两种主题下都看过
- [ ] 纯图标按钮有 `aria-label` 和 `data-tooltip`，没有用 `title`
- [ ] 不能用的按钮用 `aria-disabled`，气泡说明原因
- [ ] 弹出层能用点外面和 Esc 关闭
- [ ] 输入框加了 `nodrag`（防止拖动节点），快捷键在输入框里不会触发
- [ ] 文案是中文
