# 画布留言：让 Agent 像助手一样被“指派”任务

> 状态：已实现（2026-10-08）。和方案的差别：节点被删除后，它的留言只在面板列表里出现，画布上不再画图钉（不知道原来的位置）。日期：2026-10-08。
> 相关：`2026-09-23-film-copilot-agent-design.md`（Agent 总体设计）、`docs/DESIGN.md`（界面规范）。

## 1. 目标

用户在画布上任意位置点一下，留一句修改意见，Agent 就接手去做：
- 位置可以是空白处、某个节点、图片里的某个点，或者视频某一刻画面里的某个点。
- 每条留言都是一个子任务，由一个独立的 Agent 对话承载。
- Agent 拿到的不只是文字，还有“指的是哪里”。

做到之后，画布 Agent 从“旁边的聊天框”变成“被你在作品上指派任务的助手”。

## 2. 已确认的决定

| 问题 | 决定 |
| --- | --- |
| 留言和对话的关系 | 一条留言 = 一个 Agent 对话。原来的自由对话保留，相当于“总指挥” |
| 改出来的结果放哪 | **替换节点原图，保留历史版本**。Agent 读画布时只看当前版本，要回看时用工具读历史 |
| 点开图钉 | 在图钉旁弹一个小窗；右侧 Agent 面板里也有对应的对话，两边实时同步（同一份数据） |
| 局部修改 | 先用“参考原图重画”：原图作参考，改写提示词，重新生成整张。以后再接带遮罩的编辑模型 |
| 视频 | 先只做“某一刻的某个点”，不做时间区间。在播放中的视频上点留言时自动暂停 |
| 历史入口 | 三处：并入 Agent 面板的“全部对话”（主入口）、左侧栏“留言”按钮、节点上的留言角标 |

## 3. 交互

### 3.1 留言模式

- 左侧栏新增“留言”按钮（快捷键 C）。点了进入留言模式，鼠标变成图钉样式；Esc 或再按一次退出。
- 留言模式下点一下，就在那里放下一个图钉，并弹出输入小窗（写留言，Enter 发送，Esc 取消）。
- 点在哪里，决定了图钉锚定在什么上：

| 点在哪 | 锚定 | 记录 |
| --- | --- | --- |
| 空白处 | 画布 | 画布坐标 |
| 节点上，但不在画面里（标题栏、输入区） | 节点 | 节点 ID |
| 图片画面上 | 节点里的这一版图 | 节点 ID、版本、画面内的相对位置 (x, y)，取值 0–1 |
| 视频画面上 | 节点里的这一版视频的某一刻 | 节点 ID、版本、时间点（秒）、画面内相对位置 |

- 视频在播放时被点：先暂停在当前帧，图钉记下这一帧的时间。用户看到的帧就是 Agent 拿到的帧。
- 留言模式下，点击不会选中节点，也不会拖动节点。

### 3.2 图钉

- 外观：一个带状态颜色的小圆形图钉，不随画布缩放而变大变小（和菜单一样固定大小）。

| 状态 | 含义 | 图钉样式 |
| --- | --- | --- |
| 排队中 | 等前面的留言做完 | 灰色 |
| 处理中 | Agent 正在做 | 白色，带转动的细环 |
| 等你确认 | 有需要确认的操作 | 琥珀色，轻微脉动 |
| 已完成 | Agent 做完，等你看 | 绿色，带白色勾 |
| 已解决 | 你点了“解决” | 默认不在画布上显示 |

- 锚定在节点上的图钉跟着节点移动。节点被删除后，图钉变成“节点已删除”，留在原位置，但不能再继续执行。
- 图片 / 视频上的图钉钉在某一版上。节点换了新版本后，旧图钉显示成“针对上一版”（半透明）；点开时小窗里显示当时那一版的缩略图。
- 视频上的图钉：
  - 进度条上有对应的小标记。
  - 播放到该时间点前后约 0.5 秒时，图钉在画面上淡入，过去后淡出。
  - 点进度条上的标记，会跳到那个时间点并暂停。
- 节点收起时（未选中的沉浸式卡片），画面上不画图钉，卡片角上显示“N 条留言”角标。
- 图钉多了的时候，左侧栏的留言按钮可以“隐藏画布上的图钉”。

### 3.3 留言小窗

- 点图钉弹出，锚在图钉旁边，不随画布缩放，平移或缩放画布时跟着图钉走。
- 内容：
  - 留言原文，以及之后的往来：你的回复、Agent 的回复和步骤；
  - 确认卡片（需要确认的生成也在这里确认）；
  - 底部输入框，可以接着回复；
  - 「解决」按钮，以及「在面板中打开」。
- 小窗只显示精简内容：Agent 的文字回复、步骤摘要、确认卡片。完整内容（技能、搜索来源、任务清单）在面板里看。
- 小窗和面板是同一个对话，任何一边的新消息都实时出现在另一边。

### 3.4 历史入口

1. **Agent 面板 →「全部对话」**，顶部加筛选：全部 / 留言 / 对话。
   - 留言条目显示：图钉位置的小缩略图（视频注明时间点），留言第一句，状态。
   - 点一下：画布移到图钉、弹出小窗，面板同时打开这个对话。
   - 已解决的留言收在底部「已解决」分组，可以重新打开。
2. **左侧栏「留言」按钮**：角标是未解决的数量，有“等你确认”时角标变成琥珀色。
3. **节点上的留言角标**：点它打开面板，列表只显示这个节点的留言。

## 4. Agent 怎么接手

### 4.1 新建留言即开工

发出留言后，后端会：
1. 建一个类型为“留言”的 Agent 对话，记下锚点；
2. 进入任务队列（见 4.4）；
3. 轮到它时自动开始，第一条消息就是留言文字，加上下面的位置上下文。

### 4.2 给 Agent 的位置上下文

文字部分附在消息前面，例如：
```
[留言位置] 图片节点「图片 3」第 2 版，画面内 (62%, 30%) 处（见附图里的红圈）
```
图像部分随第一条消息一起发：
- **图片**：当前这一版缩到长边 1024，在留言位置画一个醒目的圆圈和十字；再附一张以该点为中心的放大图（大约原图的 1/3 区域）。
- **视频**：在留言时间点取一帧，同样画圈并附放大图；另外取前后各约 0.5 秒的两帧（不画圈），让 Agent 看出动作的走向。附上时间点和视频总长。
- **空白处**：不附图，只给画布坐标，以及附近最近的两三个节点的名字。Agent 在这里新建节点时，以这个坐标为起点摆放。
- **节点（不在画面里）**：只给节点名和 ID。

“画圈”比只给坐标可靠：模型认得出图上标出来的位置，却不太能把数字换算成画面里的位置。

### 4.3 改图：替换原图，保留历史

- 新增节点版本记录。每次节点的图 / 视频变化（生成、上传、Agent 改动），都记一条版本：素材、来源（生成 / 上传）、当时的提示词和参数、由哪条留言触发。
- 生成完成时，节点换成新版本（现在就是这样做的，只是旧的没留记录）。
- 新工具（只读）：
  - `get_node_versions(node_id)`：列出一个节点的历史版本。
  - `view_asset(node_id, version=N)`：看指定的某一版，`view_asset` 原来就有，加一个版本参数。
- 画布上：节点「⋯」菜单里加「版本历史」，可以看缩略图列表、切回某一版。切回只是换成显示那一版，不新增版本（2026-10-08 按用户意见改），不删除任何东西。
- 局部修改的做法：Agent 用当前版本作参考图，把提示词改成“保持其余不变，只把〔位置描述〕改成……”，然后重新生成。它要在回复里诚实说明：这是整张重画，别处也可能有细微变化。

### 4.4 并发和顺序

- 同一张画布上，留言任务同时最多跑 2 条，其余排队（图钉显示“排队中”）。
- 锚定在同一个节点上的留言按留言顺序依次处理，不会同时处理。
- 权限档位照旧用画布的设置；需要确认的操作，在小窗和面板里同时出现确认卡片，确认一处就行。
- 总指挥对话不占这 2 个名额。

### 4.5 结束和解决

- Agent 做完后，图钉变成“已完成”，小窗里是结果和一句说明。
- 你点「解决」后，图钉收起，对话归入“已解决”。你也可以继续回复，让它接着改。
- 不满意又不想继续，可以用对话里现有的「撤销这一轮的改动」：节点会回到上一版，因为版本记录里有。

## 5. 记忆：加一层“画布任务记录”

现在的三层不变：项目记忆、我的偏好、同一画布其他对话的列表。新增：
- **画布任务记录**：每条留言被解决（或 Agent 做完）时，记一句结果，例如「图片 3：背景换成清晨厨房（第 2 版），用户已解决」。
- 所有对话（总指挥和每条留言）的每条消息前面，都带上最近约 10 条任务记录。所以你在主对话里说“把刚才改过的几张统一一下色调”，它知道是哪几张。
- 长期有效的设定（“围巾永远是红色”）照旧由 Agent 记进项目记忆，不放进任务记录。
- 留言对话本身做完就可以不再出现在“其他对话”上下文里，只留任务记录那一句，省上下文。

## 6. 以后再做（这次不做）

- 进度条上拖一段时间区间来留言。
- 带遮罩的局部编辑模型：框选区域变成遮罩，只重画这一块。模型登记表加“编辑类模型”。
- Agent 主动给你留言：比如用“点评作品”技能时，把问题直接钉在图上。
- 留言模式下拖一个框（区域留言）。

## 7. 实施分步

1. **数据和后端基础**：
   - 留言表（锚点、版本、状态、所属对话）；
   - 节点版本表（生成和上传时写入，旧数据从生成记录补建）；
   - 留言 API（新建、回复、解决、重新打开、列表）；
   - 任务队列（每画布 2 个名额，同节点串行）。
2. **Agent 侧**：
   - 留言对话的启动和位置上下文：画圈截图、放大图、视频前后帧；
   - 版本工具；
   - 任务记录写入，并加进上下文；
   - 系统提示词更新。
3. **画布侧**：
   - 留言模式；
   - 图钉的渲染、状态和锚定，视频进度条标记；
   - 小窗；
   - 节点留言角标；
   - 「⋯ → 版本历史」。
4. **面板侧**：
   - 全部对话的筛选、留言条目、已解决分组；
   - 小窗和面板的实时同步；
   - 左侧栏按钮和角标。
5. **验收**：后端、前端测试，浏览器里走一遍完整流程，更新 DESIGN.md、开发日志、AGENTS.md。

每一步做完都可以单独提交和试用，第 1、2 步完成后，就能先用 API 验证 Agent 拿到位置后的表现。
