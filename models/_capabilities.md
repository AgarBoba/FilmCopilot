# 模型功能词表

每个模型的 JSON 里 `capabilities` 只能用这张表第一列的词（拼错了画布会在模型说明里报错）。
画布 Agent 读这张表来理解「这个模型能干什么」，选模型时按功能筛选。

新增一个词：在表里加一行，写清意思和使用要点，然后就能在模型 JSON 里用了。

| 功能 | 意思 | 使用要点 |
|---|---|---|
| text_to_image | 文生图：只靠提示词出图 | 没有参考图时也能用 |
| image_edit | 参考图生图 / 改图：按提示词改一张或几张参考图 | 提示词里说清楚保留什么、改什么 |
| text_to_video | 文生视频：只靠提示词出视频 | 没有参考图时也能用 |
| first_frame | 首帧生视频：第一张参考图就是视频的第一帧 | 老式接口；参考图按连线顺序，第 1 条连线是首帧 |
| first_last_frame | 首尾帧生视频：第 1 张是首帧，第 2 张是尾帧 | 老式接口；按连线顺序决定首尾，要换顺序就断开重连 |
| motion_control | 动作控制：按参考视频里的动作驱动参考图里的角色 | 老式接口；通常要 1 张角色图 + 1 段动作视频 |
| reference_video | 视频参考：参考已有视频的镜头、动作或风格 | 注意参考视频的时长上限 |
| audio | 能同时生成声音（环境音、对白、配乐） | 不要声音时记得关掉，通常也更便宜 |
| omni_reference | 全能参考：图片、视频、音频随便连，模型自己判断每个参考怎么用（当首帧、当角色、当动作、当风格都行） | 在提示词里用 [Image1]、[Video1] 这样的编号逐个说明每个参考的用途；注意总数上限；需要首尾帧、动作参考时优先用这类模型，比老式接口灵活 |
